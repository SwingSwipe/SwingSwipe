New + Updated Components
HeroHeader new
Gradient header (#064e35 → #1D9E75 → #34d399) with decorative circles. Two variants: Discover (greeting + game-count nudge pill) and Profile (avatar + name + stats row). Shared component used in both pages.
GameCard new
Replaces the current inline card JSX. Shows: host avatar + name + star rating + "hosting · Xh ago", course name (bold 800), date/time/spots meta, avatar spot indicator (circles), tags row. Join button = solid green pill. Full / past = outline or muted.
PlayerCard update
Keep structure, update visual weight — bolder name, new tag styles, same star rating. No layout change needed.
BottomNav update
Keep same JSX. Update: active dot moves to above icon (already exists), stronger shadow on nav bar, slightly taller hit area. No logic changes.
Modal update
Bump border-radius from 12px → 24px on the sheet. Stronger backdrop blur. No logic changes.
index.css cleanup
Remove leftover Vite template vars: --accent: #aa3bff, --accent-bg, --social-bg. Set new custom properties for the token set. Fix #root width (currently 1126px — wrong for a mobile PWA).
Skeleton update
Update GameCardSkeleton to match new GameCard shape — host row at top, course title, spot circles skeleton.
